== Synopsis
[verse]
aerospace [-h|--help] [-v|--version] <subcommand> [<subcommand-options>...] [<subcommand-arguments>...]

== Description

HyprSpace is an macOS tiling window manager with dwindle layouts and window groups

*aerospace* command line program is used to manipulate HyprSpace and query its state.

See https://github.com/Li-RC/HyprSpace/blob/main/docs/commands.adoc for available <subcommand> options

See each <subcommand> individual man page for <subcommand-options> and <subcommand-arguments>

== Options

-h, --help:: Print help
